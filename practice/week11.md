# Week 11 실습

## 오늘 한 것
이번 실습에서는 `Space_Fighter` 프로젝트를 실행 파일 형태로 배포하기 위해 PyInstaller를 활용한 빌드 작업을 진행하였다.  
처음에는 파이썬 파일 상태에서는 정상 실행되던 게임이 `.exe` 파일로 빌드한 뒤 실행 직후 종료되는 문제가 발생하였다. 이를 해결하기 위해 빌드 환경과 리소스 경로 처리 방식을 점검하였다.  
또한 게임에서 사용하는 이미지, 애니메이션, 효과음, 배경음악이 모두 `Assets` 폴더에 들어 있기 때문에, 실행 파일에서도 해당 리소스를 정상적으로 읽을 수 있도록 빌드 설정을 수정하였다.  
이 과정에서 `.spec` 파일을 수정하여 `Assets` 폴더가 빌드 결과물에 포함되도록 하였고, 실제로 다시 빌드한 뒤 `.exe`가 정상적으로 실행되는 것까지 확인하였다.

## resource_path()를 써야 하는 이유
파이썬 코드 상태로 실행할 때는 현재 파일 위치를 기준으로 이미지나 사운드 파일을 불러올 수 있다. 하지만 PyInstaller로 빌드한 실행 파일은 내부적으로 임시 폴더에 압축을 풀어서 실행되기 때문에, 기존과 같은 방식으로는 `Assets` 폴더를 찾지 못하는 경우가 생긴다.  
즉, `.py` 파일로 실행할 때와 `.exe` 파일로 실행할 때 리소스가 위치하는 기준 경로가 달라질 수 있다.  
따라서 실행 환경에 따라 경로를 올바르게 잡아주는 함수가 필요하며, 이번 실습에서는 `resource_path()`와 같은 역할을 하는 함수를 추가하여 이 문제를 해결하였다.  
이 함수를 사용하면 일반 파이썬 실행 환경에서는 현재 파일 기준 경로를 사용하고, PyInstaller 실행 환경에서는 `sys._MEIPASS` 경로를 기준으로 리소스를 찾도록 만들 수 있다.  
결과적으로 이미지, 효과음, 배경음악 같은 에셋을 빌드 후에도 안정적으로 불러올 수 있다는 점에서 매우 중요하다.

## 빌드 명령어
오늘 사용한 주요 명령어는 다음과 같다.

```powershell
pip install pyinstaller
pyinstaller Space_Fighter.py
pyinstaller --version
```

빌드 후 실행 확인은 아래와 같이 진행하였다.

```powershell
python .\Space_Fighter.py
.\dist\Space_Fighter\Space_Fighter.exe
```

## AI 활용 내역
이번 실습에서는 AI를 문제 해결 보조 도구로 활용하였다.  
먼저 `.exe` 파일이 실행 직후 종료되는 원인을 찾기 위해 AI에게 빌드 구조와 오류 가능성을 분석해달라고 요청하였다. 이를 통해 단순한 코드 오류가 아니라 `pygame` 설치 여부, `.spec` 파일 설정, 리소스 포함 여부 같은 배포 환경 문제까지 함께 점검할 수 있었다.  
또한 AI에게 실행 파일 환경에서 리소스를 안정적으로 읽을 수 있도록 경로 처리 함수를 추가하는 방법을 부탁하여 활용하였다. 이 과정에서 `sys._MEIPASS`를 이용한 방식의 필요성을 이해할 수 있었다.  
추가로 `.spec` 파일에 `Assets` 폴더를 포함시키는 방법과, 빌드 후 실행 확인 절차도 AI의 도움을 받아 정리하였다.  
마지막으로 한글 문자열이 깨진 부분과 실행을 방해하는 문법 오류도 AI에게 복구를 부탁하여 수정하였다.  
정리하면, 이번 실습에서 AI는 단순히 코드를 작성하는 역할만 한 것이 아니라, 빌드 오류 원인 분석, 실행 환경 차이 설명, 설정 파일 수정, 디버깅 과정 정리에 이르기까지 전반적인 개발 보조 도구로 활용되었다.
